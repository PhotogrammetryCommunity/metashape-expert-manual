# Project Status

A 60-second snapshot of where the Metashape Expert Manual stands.

**Last updated:** 2026-06-05

## Where things stand

The manual is **published** via GitHub Pages at
<https://photogrammetrycommunity.github.io/metashape-expert-manual/>.
It is built from `docs/` with MkDocs Material and deployed
automatically by `.github/workflows/deploy.yml` on every push to
`main`.

- **150+ articles** across the workflow (photogrammetry pipeline),
  cross-cutting topics, and reference sections.
- **Build:** clean under `mkdocs build --strict` — broken links and
  missing nav entries fail the build.
- **Agisoft Knowledge Base index:**
  `docs/reference/agisoft-knowledge-base.md` inventories the
  183-article Agisoft Freshdesk Knowledge Base with a short summary per
  article (regenerated by `scripts/gen_kb_reference.py`). Manual
  articles cross-reference the relevant KB entries in the house format
  `[*Title* (Agisoft KB)](url)`.

## Verification model

Every article carries a `status:` field and goes through three tiers:

| Tier | Done by | Confirms |
|------|---------|----------|
| 1 | scripts (Python API introspection, PDF text extraction) | API kwargs, GUI menu paths, terminology |
| 2 | automated editorial + technical review | template, voice, citations, Diátaxis discipline |
| 3 | a human at the real Metashape GUI on sample data | runtime correctness, dialog behaviour |

Articles stay `unverified` until a maintainer completes Tier 3 on a
real install. Tier 1 is a prerequisite for Tier 2.

## Maintenance mode

The corpus is feature-complete and in maintenance:

- Tier 3 verification — walking `unverified` articles through a real
  Metashape install on sample datasets.
- Periodic refresh as new Metashape versions land (see
  `corpus/README.md` for the forum- and KB-refresh recipes).
- Ad-hoc additions when new forum threads or field insights surface
  novel topics.
