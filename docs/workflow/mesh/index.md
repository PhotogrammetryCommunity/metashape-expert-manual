# Mesh

Articles on building, exporting, and post-processing the
polygonal mesh model — Metashape's primary 3D output for
non-tiled workflows.

For Metashape's own definitions, see [the
glossary](../../reference/glossary.md). For the current Python
API surface, see *Metashape Python API Reference* version
2.3.1, especially `Metashape.Chunk.buildModel`,
`Metashape.Chunk.exportModel`, and `Metashape.Model`.
