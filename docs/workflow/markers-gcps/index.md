# Markers, GCPs, scale bars

Articles on placing, managing, and cleaning up markers — the
Metashape object that subsumes ground-control points (GCPs), check
points, and reference fiducials.

For Metashape's own definitions, see [the glossary](../../reference/glossary.md).
For the current Python API surface, see *Metashape Python API
Reference* version 2.3.1, especially `Metashape.Marker`,
`Metashape.Marker.Projection`, and `Metashape.Marker.projections`.
