# Orthomosaic

Articles on building, exporting, and post-processing orthomosaics
— the planar 2D raster product of a textured surface re-projected
to a regular grid.

For Metashape's own definition of orthomosaic terms, see
[the glossary](../../reference/glossary.md). For the current
Python API surface, see *Metashape Python API Reference* version
2.3.1, especially `Metashape.Chunk.buildOrthomosaic`,
`Metashape.Chunk.exportRaster`, `Metashape.OrthoProjection`,
and `Metashape.BBox`.
