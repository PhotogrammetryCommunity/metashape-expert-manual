# Features

Per-feature reference pages aggregating everything the manual knows about
a specific Metashape feature or concept. Use this section when you want
to know *what* a feature is, *where* it lives in the GUI / Python API,
and *where to learn more* about it across articles, official docs, and
the forum.

This is reference material, not problem-solving advice — for the latter,
see [Workflow](../../workflow/index.md) and [Topics](../../topics/index.md).
