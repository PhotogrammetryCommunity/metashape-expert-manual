# Reference

Look-up material — glossary, version-difference matrices, parameter tables.

Reference articles are intentionally short and information-dense. They are not
how-tos and they do not explain reasoning — they follow the
Diátaxis *reference* discipline (see the [style guide](../about/style.md)).

In this section:

- [Glossary](glossary.md) — short, neutral term definitions.
- [Sample datasets](sample-data.md) — Agisoft's ten free sample
  datasets, with what each illustrates best. Use them when validating
  or illustrating articles.
- [Version timeline](version-timeline.md) — release date → product
  version → headline changes. Used to resolve a forum-post date to a
  cite-as version.
- [Version differences](version-differences.md) — behavioural diffs
  between Metashape versions.
- [Features](features/index.md) — per-feature reference pages that
  aggregate articles, forum threads, and API references for a
  specific Metashape feature or concept.
